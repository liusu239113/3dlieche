# 火车驾驶模拟（3dlieche）

基于 UrhoX 引擎的 Lua 火车驾驶模拟游戏。

## 玩法

- 一条闭合环线，5 座车站：北京 → 天津 → 济南 → 南京 → 上海 → 北京
- 蓝白长机罩内燃机车 + 7 节客车编组
- 油门 8 档、空气制动、紧急制动、换向、汽笛
- 在站台容差内停稳接站，获得经验；站停结束后发车

## 操作

| 按键 | 功能 |
| --- | --- |
| W / S | 油门 + / − |
| SPACE | 按住持续制动 |
| B | 缓解（释放制动力） |
| X | 紧急制动 |
| H | 汽笛 |
| R | 换向（前进 / 后退） |
| C | 切换视角（跟随 / 侧视 / 司机） |
| A / D | 相机水平环绕 |
| ↑ / ↓ | 相机俯仰 |
| P | 暂停 |

触屏：拖动油门 / 制动手柄调档，按住制动持续加压，松手保压，「缓解」按钮释放制动力。

## 目录结构

```
scripts/     游戏 Lua 源码
  main.lua     入口
  config/      参数与材质配置
  world/       线路、轨道、站台、地形
  train/       机车、客车、相机
  ui/          驾驶仪表 HUD
  game/        到站与玩法逻辑
  tests/       离线验收脚本
assets/      模型、贴图、音频
.project/    工程配置
```

## 构建

使用 UrhoX / 星火编辑器（SCE）构建，入口为 `scripts/main.lua`。
